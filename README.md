# Power BI Projects

Учебные проекты по аналитике и визуализации данных в Power BI, выполненные в рамках курса "Аналитик данных" (Academica, 2026).

## Стек

Power BI (Power Query, DAX, модель данных), MySQL

## Проекты
**1. Sample Super Store project**

Анализ продаж розничной сети (датасет Sample Superstore) — построение отчёта для руководства с ключевыми метриками эффективности и разрезами по географии, клиентам и продуктам.

**Реализовано:**

- KPI-метрики (DAX): Sales, Profit, Profit Ratio, Profit per Order, Sales per Customer, Average Discount, Total Quantity.
- География: карта Profit Ratio по штатам.
- Динамика: месячные продажи в разрезе сегментов и категорий продукта (Order Date).
- Продукты и клиенты: матрица продаж/прибыли по продукту и категории; диаграмма продаж по клиентам с сортировкой по убыванию.
- Регионы: отдельные диаграммы по продажам, прибыли, количеству проданных товаров и Profit Ratio.
- Доставка: нормированная диаграмма распределения статусов доставки (Ship Status) по областям, в разрезе количества товаров.

**Цель:** дать руководству единую панель для оценки прибыльности по регионам, категориям и клиентам, а также выявить проблемные зоны в логистике (задержки и статусы доставки).

**2. Power BI Final Project**

Комплексный отчёт для e-commerce/ритейл-компании, столкнувшейся со снижением продаж — от подключения к базе MySQL и построения модели данных до многостраничного дашборда с бизнес-инсайтами.

**Данные:** 12 связанных таблиц (заказы, продажи, клиенты, склады, сотрудники, тарифы доставки и др.), период — около одного года.

**Структура отчёта:**

1. Продажи и прибыль:	Total Sales, Cost, Profit, Profit Margin %, динамика продаж, топ-5 категорий, фильтр по статусу заказа
2. Логистика и склады:	остатки по складам, выручка по складам с drill-down по датам, затраты на доставку по методам и регионам, KPI "расходы на доставку / выручка"
3. Клиенты и регионы:	распределение клиентов по регионам (карта), количество заказов по городам, средний чек, динамика новых клиентов
4. Сотрудники и эффективность:	численность персонала по складам, зарплатный фонд, выручка на одного сотрудника, фильтр по должности

**Ключевые DAX-меры:** Total Sales, Total Cost, Profit, Profit Margin %, Average Order Value, Sales YOY %, Returns Rate %.
